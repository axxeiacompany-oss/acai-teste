# Açaí do Japa - Santa Maria Norte

Cardápio digital interativo e vitrine de alta gastronomia para o **Açaí do Japa**, localizado em Santa Maria Norte, Distrito Federal ("O Melhor da Cidade!!").

## 🍇 Funcionalidades

- **Cardápio Digital Completo**: Categorias exclusivas de açaí artesanal, mixes com frutas, cremes nobres (Cupuaçu, Ninho, Pistache), barcas e taças gourmets, além da Linha Fit & Growth.
- **Monte Seu Açaí Interativo**: Montador em tempo real com visualização dinâmica de camadas (base, cremes, frutas, coberturas e adicionais nobres como Ferrero Rocher e Nutella pura).
- **Sacola de Pedidos & Checkout**: Carrinho completo com cálculo de subtotais, aplicação de cupom promocional (`JAPA10`), seleção de entrega ou retirada no balcão e formatação automática para envio no WhatsApp.
- **Clube Fidelidade VIP**: Simulador de pontuação e resgate de prêmios por número de telefone.
- **Informações Locais**: Horários de funcionamento (13h às 23:30h), endereço físico em Santa Maria Norte e mapa de atendimento térmico.

## 🚀 Como Executar Localmente

### Pré-requisitos
- Node.js (versão 18 ou superior)
- npm ou yarn

### Instalação

```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento
npm run dev

# Gerar build de produção
npm run build
```

## 🛠️ Tecnologias Utilizadas

- **React 19** + **TypeScript**
- **Vite 6**
- **Tailwind CSS v4**
- **Lucide React** (Ícones)
